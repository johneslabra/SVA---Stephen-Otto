# Extra skills catalog

A second list of add-on skills the AI can install, from the library at
https://www.aitmpl.com/skills/, checked on 2026-09-21.

That library holds 888 skills. Every one was downloaded and read. Most are for software
engineers, scientists, security auditors or startup founders, and were thrown away. The
**89 below are the ones that are actually useful for agency VA work**, each with a
plain description of what it does and how useful it is likely to be.

**Use `skills/SKILLS-CATALOG.md` first.** Come here only when nothing there fits.
See "When you can't do something" in `CLAUDE.md`.

Every skill here was confirmed to exist and to be properly formed on the date above.
They come from one library, `davila7/claude-code-templates`, and are community-written,
so read the skill's own instructions before using it.

**Usefulness** — *High* means a VA is likely to reach for it. *Medium* means it is good
when the job calls for it, but that will not be every week.

**"Setup needed"** in the last column means the skill will not work until someone adds a
login or key for it. Do not attempt that yourself, and never put a key in this folder.
Tell the VA to ask their lead, and carry on without the skill for now.

## What was dropped, and why

So a future reader does not re-check the same 888 skills: the discarded ones were
software engineering (React, databases, deployment), scientific research, security
auditing, medical-device and ISO/FDA regulatory work, chat-bot building, startup and
product-management advice, and anything written for one product a client is unlikely
to use. Also dropped: duplicates, entries with no working description, and one written
only in Chinese.

If a VA asks for something that sounds like it should be here and is not, it was
probably one of those. Say so plainly and do the task as well as you can without it.

## How to install one of these (for the AI)

1. The *Path* column is the skill's location in the library.
2. Fetch that one folder:

   ```bash
   git clone --depth 1 https://github.com/davila7/claude-code-templates /tmp/cct
   cp -r "/tmp/cct/cli-tool/components/skills/<PATH>" ".claude/skills/<skill-name>"
   ```

   Copy only that folder. It contains `SKILL.md`.
3. Read the `SKILL.md`. If it needs a key or a login, stop and tell the VA to ask the lead.
   Never put keys in the repo.
4. Run `bash scripts/sync.sh` so the whole team gets the skill.
5. Add a line to `skills/INSTALLED.md`: date, skill name, who asked, why, and note it came
   from this list rather than the main catalog.

If the path no longer works, the library has moved or removed the skill. Do not go hunting.
Tell the VA the add-on is not available and do the task as well as you can without it.
