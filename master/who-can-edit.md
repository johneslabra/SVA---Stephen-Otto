# Who can change these master files

The files in this folder hold the core client details: the business, the brand,
the people, the tools, the working rules. Everything else in the client folder
is built on top of them, so they are protected. Only the people listed below can
change them. Everyone else can still read them, and can work normally everywhere
else in the folder.

The one exception is `faqs.md`, the customer FAQs. Anyone can add to that.
